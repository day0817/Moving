# 近さ優先シナリオ 調査レポート（全種別・居室3以上・60m²以上・築40年以下・敷地内駐車場）

## 1. 概要と背景

郊外・広さ優先の現行条件（一戸建て 80m²以上・築30年以下・ドアドア59分以下）に対し、大手町までの「近さ」を最優先した場合の妥協量と市場供給を調査しました。

一戸建て限定で面積・築年数の制限を撤廃した調査（[ドアドア30分シナリオ.md](ドアドア30分シナリオ.md)）では、30分以内の物件（10件）の7割が1K〜2DK（25〜54m²）の単身・狭小住宅となり、ファミリー向けの実用性に欠けることが判明しました。

そこで本調査では、**居室3以上（3DK/3K/3LDK/4K以上）を必須** とし、建物種別を **全種別（マンション・アパート・テラスハウス・一戸建て）** へ拡大。さらに実生活上の必要条件として **専有面積 60m²以上・築40年以下・敷地内駐車場付き（有料可、近隣不可）** を指定した場合の供給量と物件一覧を定量化しました。

## 2. 結論（帯別の件数と妥協の急所）

自己負担上限 5.0万円以下（社宅制度上限17.0万円まで2割＋超過分全額＋駐車場代実費）の枠内での成立件数です。（2026/09/23時点）

| :----------------- | :----------------------: | :----------------------------------- | :------------------------------------------------------------------------------- |

### 妥協の急所（スイートスポット）

- **30分以下** に固執すると **3軒**（西葛西・葛西・大島）に限られ、自己負担額も上限枠いっぱい（4.4万〜4.9万円）になります。
- しかし、所要時間をわずか5分緩めて **35分以下** にすると件数は **13軒（約4.3倍）** に急増します。特に **東京メトロ東西線（浦安駅・妙典駅）** において、駅徒歩4〜11分・敷地内駐車場付きの良質な3LDK（60〜65m²、自己負担4.1万〜4.9万円）がまとまって出現します。
- 通勤近さを優先し直す場合、**「ドアドア35分以内・東西線沿線（浦安〜妙典）」** が最もバランスの取れた現実解となります。

## 3. 再現・検索手順（検索方法）

本調査のデータ取得・集計パイプラインは、以下の手順でいつでも再実行・最新化できます。

### 3.1 実行コマンド（PowerShell）

```powershell
# 1. 環境変数の設定
$env:PYTHONIOENCODING="utf-8"

# 2. SUUMO一覧取得（大手町30分・家賃18万以下・全種別・居室3以上）
py scripts/scenario_search.py --stage fetch --tj 30 --max-rent 18.0 --all-types --min-bedrooms 3 --work-dir .work/d2d30_all_3r

# 3. 新規駅の洗い出し（既存390駅DBを引き継ぎ）
py scripts/scenario_search.py --stage stations --work-dir .work/d2d30_all_3r --min-bedrooms 3 --base-extra-csv .work/d2d30/station_commute_extra.csv

# 4. 新規駅の通勤時間実測（未取得駅がある場合のみGoogleマップで実測）
node scripts/fetch_extra_station_commute.js --csv .work/d2d30_all_3r/station_commute_extra.csv

# 5. 候補物件の詳細ページから駐車場代を取得・解析
py scripts/scenario_search.py --stage parking --work-dir .work/d2d30_all_3r --min-bedrooms 3 --base-extra-csv .work/d2d30/station_commute_extra.csv

# 6. 集計・候補物件一覧テーブル生成
py scripts/scenario_search.py --stage report --work-dir .work/d2d30_all_3r --min-bedrooms 3 --base-extra-csv .work/d2d30/station_commute_extra.csv
```

### 3.2 フィルタリング条件（60m²以上・築40年以下・敷地内駐車場）

集計データ（`.work/d2d30_all_3r/candidates.json`）に対し、以下のスクリプト（`scratch/filter_60m_40y_onsite.py`）で絞り込みを実行します。

- 専有面積: 60.0m²以上
- 築年数: 40年以下
- 駐車場: `parking_dist == 0` かつ 表記が「敷地内」または「付無料」
- 自己負担額: 5.0万円以下

## 5. エリア別の供給構造と留意点

1. **東西線沿線（葛西〜浦安〜妙典）の圧倒的優位**:
   - 24軒中 **16軒が東西線沿線** に集中しています。
   - 大手町直通で乗り換えがないため、物件徒歩が10分程度あってもドアドア32〜38分に収まります。
   - 千葉県側（浦安・妙典）に入ると敷地内駐車場の相場が **月額1.1万〜1.5万円** に下がり、自己負担枠（5.0万円）に無理なく収まりやすくなります。
2. **駐車場代の自己負担枠圧迫**:
   - 都内区部（西葛西・葛西など）では敷地内駐車場が月額1.8万〜2.3万円するため、家賃＋管理費が13万〜14万円台であっても自己負担が4.8万〜4.9万円に達します。
   - 家賃が15万円を超えるマンションで敷地内駐車場を借りる場合、自己負担上限5.0万円を確実に超過するため、市場から自然に除外されます。
3. **教育・学区環境**:
   - `doc/背景.md` で重視されている小中一貫校・文教環境（日吉・川崎中原・松戸新田等）に対し、本シナリオのエリア（江戸川区・市川市・浦安市）は下町住宅街・湾岸近接エリアが中心となります。教育環境の検証は別途必要です。
