# ドキュメント一覧

引越先（大手町・東京サンケイビル通勤）向け 賃貸一戸建て探しのための調査・検討資料。

## 目的別の読み方

| 知りたいこと | 見るファイル |
| :--- | :--- |
| なぜ引越すのか・新居の要件（予算/通勤/教育） | [背景.md](背景.md) |
| 候補エリアごとの通勤・住環境・供給状況の比較 | [エリア比較.md](エリア比較.md) |
| 直近スクレイピングでヒットした物件の一覧と前回差分 | [物件検索結果.md](物件検索結果.md) |
| 更新日ごとの駅別物件数の推移と冬に向けた候補エリア推測 | [物件数推移.md](物件数推移.md) |

## 種別

- **背景.md / エリア比較.md** … 手動で更新する要件・分析ドキュメント。
- **物件検索結果.md / 物件数推移.md** … `property_search` スキル（`.agents/skills/property_search/`）が
  自動生成・追記するレポート。手動編集した内容は次回スクレイピングで上書きされる可能性があるため注意。
