SUUMOで物件を検索する際、駅Aと駅Bが異なる場合がある。
・駅A：指定駅（大手町）までの通勤時間判定に用いる駅
・駅B：物件から駅までの徒歩時間を測定する駅

今は、ドアドア時間として大手町～駅Aの時間+駅B～物件までの徒歩時間となり、実態と乖離がある。
正しくは、ドアドア時間は大手町～駅Bの時間+駅B～物件までの徒歩時間である。

SUUMOから得られる情報は物件からの最寄り駅一覧なので、その各駅について大手町（東京サンケイビル）までの時間を以下を参考に取得して、徒歩時間と合わせて正確なドアドア時間を出そう。
そして、もっとも短いものが、正しいその物件のドアドア時間だ。


'''AHK2
;; Yahoo! 路線情報（直近月曜 8:45到着） 通勤時間に合わせた時間を指定
XButton2:: {
    SavedClip := A_Clipboard
    A_Clipboard := ""
    Send("^c")
    if ClipWait(1) {
        targetDate := GetNextMondayDateTime()
        y := SubStr(targetDate, 1, 4)
        m := SubStr(targetDate, 5, 2)
        d := SubStr(targetDate, 7, 2)
        origin := Trim(StrReplace(StrReplace(A_Clipboard, "`r", ""), "`n", ""))
        Run("https://transit.yahoo.co.jp/search/result?from=" origin "&to=東京サンケイビル&type=4&ticket=ic&expkind=1&y=" y "&m=" m "&d=" d "&hh=08&m1=4&m2=5"
        )
    }
    Sleep(100)
    A_Clipboard := SavedClip
}

;; 直近の月曜日 08:45:00 の日時文字列（YYYYMMDDHH24MISS）を取得
GetNextMondayDateTime() {
    days := Mod(2 - A_WDay + 7, 7)
    if (days == 0 && SubStr(A_Now, 9, 4) >= "0845") {
        days := 7
    }
    targetDate := SubStr(A_Now, 1, 8) "084500"
    if (days > 0) {
        targetDate := DateAdd(targetDate, days, "Days")
    }
    return targetDate
}
'''
全物件に毎回上記の操作を行うのは時間がかかるのでなので、駅ごとのデータベースを作成して自動化したい。
csvで、駅名、乗換回数、到着駅（XX線大手町駅 or YY線東京駅など）、到着駅からの徒歩時間、利用路線1、2、3、を管理

初回は、候補物件すべてで確認してリスト化
2回目以降は、リストを参照して埋めて、リストに入っていないものは操作してリストに追加

---
